## 2. Classification

**Malware family: none — Confidence: Low (for malicious intent)**

This binary is internally, structurally, and behaviorally consistent with **Tencent TBS ("Tencent Browsing Service" / X5 kernel) MiniBrowser**, a legitimate embeddable Chromium/QQBrowser-derived browser component that Tencent licenses out for third-party apps to bundle:

- PDB path, internal build project number (`28820`), and file metadata all match genuine 2017 Tencent TBS SDK builds.
- Registry paths (`Software\Tencent\MiniBrowser`, `Software\Tencent\MiniBrowser\Cfg`), search-engine provider JSON configs (Baidu, Bing, Sogou, Google), `PepperFlash\pepflashplayer.dll` references, `Tencent\DeskUpdate\GlobalMgr.db`, `CreateQBDLInstance`, `GetTXBrowsingService`, `installQB` — all standard TBS/QQBrowser SDK artifacts.
- No embedded payloads, carved files, or virtual files beyond the standard VERSIONINFO/MANIFEST resources and the Authenticode PKCS7 blob (found in the overlay, which is expected and normal for any signed PE).

**KesaKode (offline + online)**: offline hinted `FatDuke` (APT29-associated malware family) at confidence 2 (raw match count). Online lookup returned **FatDuke: 2.18%**, driven by only 3 of ~1,800 classified functions matching at the function level — almost certainly generic CRT/STL code overlap, not real code sharing. Per the ≥80%/20–79%/<20% thresholds, this is **below the noise floor and is discarded entirely**. No attribution is made.

**capa**: reports only routine browser/SDK capability — registry read/write, process/thread creation, MS Detours-based hooking (used by TBS for compatibility shims), runtime API resolution, HTTP communication, Base64 encoding, MD5 hashing. Nothing indicative of a malicious capability set (no C2 beaconing primitives, no credential access, no ransomware/wiper indicators).

**Static anomalies** (malcat): XOR-in-loop and stack-string-building patterns are present (typical of MSVC-compiled C++/STL string handling and CRT init, not evidence of shellcode or a decryption stage) — no dynamically-decoded strings were found by floss, and stringsifter's top-ranked strings are entirely legitimate browser/cert-chain artifacts.

## 8. Analyst Notes

- The core binary is genuine, unmodified-looking Tencent TBS MiniBrowser SDK code from 2017 (PDB, internal project number, registry paths, and provider configs all line up). No packer, no embedded payload, no carved/virtual sub-files beyond standard PE resources.
- The signing certificate mismatch (Tencent-branded binary, signed by "Feidelai (Chengdu) Home Co., Ltd.") is the only anomaly of note. Two plausible explanations:
  1. **Benign**: Tencent's TBS/X5 browser kernel is a widely licensed, redistributable SDK — many third-party Chinese apps embed it and sign their own repackaged distribution with their own company's EV certificate rather than Tencent's. This is common practice in the Chinese software ecosystem and does not by itself indicate compromise.
  2. **Suspicious**: cert-stuffing / trust-borrowing, where an old, clean, legitimately-behaving binary is re-signed with an unrelated EV cert to gain SmartScreen/AV reputation for use elsewhere in a delivery chain (e.g., dropped alongside a malicious payload, or used as a decoy/benign-looking companion file).
- Since no malicious payload, dropper behavior, embedded file, or C2 traffic was found in this sample standing alone, and dynamic sandboxing returned a clean verdict, this sample is assessed as **low risk / likely benign on its own merits**, with the certificate anomaly noted as worth flagging if `minibrowser.exe` is encountered again alongside other files in a delivery chain (e.g., inside an installer or dropped by another sample).
- **Recommended follow-up**: if this file was found alongside other artifacts (an installer, a downloader, a dropped payload) at the same source/timestamp, analyze those companion files — the certificate here may be shared infrastructure worth pivoting on if the same serial (`320f566c4a48d5133d628a72`) or subject ("Feidelai (Chengdu) Home Co., Ltd.") appears elsewhere. No linkage to any previously tracked family in memory was found (no shared cert serial, C2, config values, PDB path, or payload hash meets the cross-reference bar).
